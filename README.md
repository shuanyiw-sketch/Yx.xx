# 个人摄影 / 妆造预约小程序

客户先浏览作品和服务，再选择实时空档提交预约；经营者确认后正式占用档期。首版不接在线支付，只记录线下订金与尾款。

## 已实现

- 双列作品流、作品详情、收藏、关联服务与“预约类似服务”
- 服务参考价、时长、前后缓冲与实时空档计算
- 24 小时待确认锁定、并发防抢、重复提交保护
- 客户预约列表、撤回、申请取消与状态提醒
- 经营者工作台、档期、预约、作品、服务、客户与主页管理
- 线下订金和尾款记录；没有支付、退款或担保交易
- 每五分钟释放过期档期，并发送预约通知和提前 24 小时提醒

## 开始使用

1. 安装微信开发者工具，用本目录的 `project.config.json` 导入项目。
2. 按 `docs/cloudbase-setup.md` 创建云开发环境、集合和索引。
3. 把店铺文档 ID 写入 `miniprogram/config.js` 的 `STORE_ID`。
4. 在微信开发者工具中分别部署 `booking-api` 和 `booking-scheduler`，选择云端安装依赖。
5. 运行自动测试，再按 `docs/acceptance-checklist.md` 用体验版进行三账号真机验收。

```bash
pnpm install
pnpm test
pnpm lint
```

部署、真实 OpenID 绑定和正式发布会改变线上状态，需要项目所有者在最后验收后操作。
