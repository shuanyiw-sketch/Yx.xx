# 体验版验收清单

自动测试已覆盖权限矩阵、作品到预约确认的主流程、并发档期、状态流转、过期释放和通知重试。以下项目需在微信体验版中，用两个客户微信和一个已绑定经营者微信完成。

## 验收前准备

- [ ] 使用独立测试 CloudBase 环境，并已创建集合、索引、权限和定时触发器。
- [ ] 已写入测试店铺、已发布服务、每周档期规则和至少三个已发布作品。
- [ ] 已绑定经营者 OpenID，两个客户账号没有经营者角色。
- [ ] 已部署两个云函数并上传微信体验版。

## 1. 作品到预约确认

- [ ] 客户 A 能刷作品、打开多图详情并看到标签和关联服务。
- [ ] “预约类似服务”带入正确服务，不承诺复制完全相同作品。
- [ ] 客户 A 选择空档并提交后显示“待确认”。
- [ ] 经营者确认后，客户刷新看到“已确认”。
- [ ] 服务编辑后，历史预约中的服务名称、参考价和时长不变。

## 2. 订阅消息接受与拒绝

- [ ] 客户 A 接受订阅消息后提交预约，状态通知可以送达。
- [ ] 客户 B 拒绝订阅消息后仍能正常提交预约。
- [ ] 消息失败只改变通知任务，不改变预约状态。

## 3. 同一档期并发

- [ ] 客户 A 与客户 B 同时提交同一服务、同一开始时间。
- [ ] 只有一笔成功，另一端提示“该时段刚刚被预约，请重新选择”。
- [ ] 失败端刷新后，该时段不再可选。

## 4. 24 小时过期释放

- [ ] 把测试预约的 `lockedUntil` 改到当前时间之前。
- [ ] 最多五分钟后预约变为“已过期”，原档期重新可选。

## 5. 取消流程

- [ ] 待确认预约可撤回并立即释放档期。
- [ ] 已确认预约申请取消后显示“取消处理中”，档期仍占用。
- [ ] 经营者同意取消后档期才释放。

## 6. 作品上传恢复

- [ ] 多图上传中途断网后，作品草稿和已成功图片仍保留。
- [ ] 恢复网络后可继续保存并发布，客户只看到已发布作品。
- [ ] 当前没有直接删除云文件入口；后续增加时必须先检查公开引用。

## 7. 账号隔离与线下收款

- [ ] 客户 B 无法打开客户 A 的预约。
- [ ] 公开作品不出现手机号、经营备注、收款记录或 OpenID。
- [ ] 其他店铺经营者无法管理当前店铺；普通客户看不到工作台入口。
- [ ] 订金和尾款合计正确，客户页面没有付款、退款或担保按钮。
